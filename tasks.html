各班のタスク

班ごとに、現在のタスクと進捗をまとめています。 次回の全体MTGは 2026年5月26日（火）です。クレーンゲーム完成（6月頭）に向けて進めています。

  1. 01

    環境整備（Discord・ドキュメントサイト）

    Discord チャンネルを整え、ドキュメントサイトを立ち上げて公開しました。
    完了
  2. 02

    各班と個別MTG

    各班と 1on1 を実施し、何を作るか・役割・宿題を共有しました。
    完了
  3. 03

    学習教材の準備

    Blender 軽い導入の説明、Wokwi の予習用リンクなどを用意しました。
    完了
  4. 04

    パーツ選定・購入・配布

    必要なパーツを Amazon で購入し、コントローラー班に渡しました。費用はサークルに請求します。
    完了
  5. 05

    Arduino コードの作成・共有

    Wokwi でプロトタイプ（ボタン・ジョイスティック・7セグ・LED）を作成しました。コードを GitHub に上げて、コントローラー班が実機で確認できるようにします。
    進行中
  6. 06

    ゲーム本体のモック制作

    クレーンゲーム本体のモックを用意し、ソフトウェア・アプリ制作班の参考実装にします。
    未着手5月末
  7. 07

    実機実装のサポート

    コントローラー班が組み立てた実機の動作確認を一緒に行い、つまずいた箇所をサポートします。
    未着手5月末〜6月頭
  1. 01

    個別MTG（Blender 軽い導入を受講）

    メンターから Blender の基本操作、モデリングの流れ、書き出しまでを共有してもらいました。
    完了
  2. 02

    筐体のラフを描く（手書き）

    筐体の見た目とパーツ配置を、紙にラフで描きます。
    • 全体の形・サイズ感（卓上型、ノートPC のキーボードくらい）
    • スティック・投下ボタン・スタートボタン・7セグの位置
    • USB ケーブルの取り出し口
    未着手 5/26までに持ち寄り
  3. 03

    ボタン・スティックのデザイン（手書き）

    投下ボタン、スタートボタン、スティック（つまみ部分）のデザインをラフでスケッチします。タクトスイッチ用の 3D プリントカバーの設計もここに含みます。
    未着手 5/26までに持ち寄り
  4. 04

    筐体の 3D モデル化（Blender）

    手書きラフをもとに、寸法を正確にした 3D モデルを Blender で作成します。後工程の 3D プリントや木工指示書のもとデータになります。
    5月末〜6月頭
  5. 05

    筐体の製作（木材または 3D プリント）

    ホームセンターで木材を購入して組むか、3D プリントで出力するかを、設計内容に応じて判断します。内部にはパーツ収納と配線スペースを確保します。
    6月頭
  1. 01

    個別MTG（何を作るか・Arduino 紹介）

    メンターと対面で 1on1 を行い、プロジェクト全体・Arduino でできること・今後の流れを共有してもらいました。クレーンゲーム用のパーツも受け取りました。
    完了
  2. 02

    自宅で実機を組み立て

    受け取ったパーツ（Arduino Pro Micro、ジョイスティック、ボタン、7セグなど）を、手持ちの工具で組み立てます。配線の参考は、メンターが作った Wokwi プロトタイプを使います。
    進行中
  3. 03

    コードを書き込んで実機で動作確認

    メンターが GitHub に上げたコードを Pro Micro に書き込み、ボタン・ジョイスティック・7セグ・LED が想定通り動くかを確認します。
    これから
  4. 04

    本番に向けた調整

    HID キーボード化、ゲームロジックに沿った動作（カウントダウン、3回繰り返し、LED 制御）を、メンターと一緒に仕上げていきます。
    6月頭
  1. 01

    個別MTG（作りたいアプリの相談）

    メンターと相談して方針を決めました。動きをリアルに表現するため、Unity 6 を採用することにしています。
    完了
  2. 02

    選んだ技術の調査

    Unity 6 で開発に着手しています。現在はアーム制御方式（MovePosition と キネマティック + Joint）の選択肢を比較しながら実装中です。
    進行中
  3. 03

    ゲーム本体の実装

    メンター提供のモックを土台に、本番用のクレーンゲームを実装します。WASD で 8方向移動、Space で投下、Enter でスタートというシンプルな入力で動かします。
    5月末〜6月頭
  4. 04

    UI とランキング機能

    以下を実装します。
    • タイトル画面（本日のトップ10 を表示）
    • プレイ中 HUD（残り時間、取得数）
    • リザルト画面（取得数、現在の順位）
    • localStorage で取得数を永続化
    6月頭
