コントローラー組み立てガイド

クレーンゲーム コントローラーの配線とプログラムをまとめています。 Arduino Pro Micro（ATmega32U4）を使い、ブレッドボード上で組み立てます。

メモ
  • 各パーツの端子の並び順（CLK / DIO / VCC / GND など）は、製品によって異なる場合があります。必ず実物に印刷された文字を見て繋いでください。この図の並び順はあくまで一例です。
  • 今回はブレッドボード上での再現でOKです。本番の筐体では、各ボタン・スティックの設置位置が離れるため、配線ケーブルが長くなります。
  • VCC と GND はブレッドボードの電源レール（＋／−）に繋ぎ、そこから 7セグとジョイスティックに分配します。
  • ボタンは INPUT_PULLUP 方式のため、片側を信号ピン、反対側を GND に繋ぎます（外付け抵抗は不要）。
  • LED には抵抗を必ず挟んでください。220Ω が目安ですが、手持ちがなければ 220Ω 以上でもOKです（明るさが少し落ちる程度）。アノード＝長い足が D6 側、カソード＝短い足が GND 側。

2. プログラミング

以下が現在のプロトタイプコードです（Wokwi で動作確認済み）。 GitHub にも置いてあります： cranegame-controller.ino 

#include <TM1637Display.h>

// ===== ピン定義 =====
#define CLK 2          // 7セグ TM1637 CLK
#define DIO 3          // 7セグ TM1637 DIO

#define BTN_DROP  4    // 投下ボタン
#define BTN_START 5    // スタートボタン
#define LED_DROP  6    // 投下ボタン照明用LED（220Ω 経由）

#define JOY_X A0       // ジョイスティック VRX (X軸)
#define JOY_Y A1       // ジョイスティック VRY (Y軸)

#define THRESHOLD_LOW  300
#define THRESHOLD_HIGH 700

TM1637Display display(CLK, DIO);

void setup() {
  Serial.begin(9600);
  pinMode(BTN_DROP, INPUT_PULLUP);
  pinMode(BTN_START, INPUT_PULLUP);
  pinMode(LED_DROP, OUTPUT);
  display.setBrightness(7);
  display.showNumberDec(0);
  digitalWrite(LED_DROP, LOW);
  Serial.println("Ready");
}

void loop() {
  // 投下ボタン
  if (digitalRead(BTN_DROP) == LOW) {
    Serial.println("DROP pressed");
    display.showNumberDec(0);
    digitalWrite(LED_DROP, HIGH);
    delay(250);
    digitalWrite(LED_DROP, LOW);
  }
  // スタートボタン
  if (digitalRead(BTN_START) == LOW) {
    Serial.println("START pressed");
    display.showNumberDec(30);
    delay(200);
  }
  // ジョイスティック（物理向きに合わせて反転済み）
  int x = analogRead(JOY_X);
  int y = analogRead(JOY_Y);
  String dir = "";
  if (y > THRESHOLD_HIGH) dir += "UP ";
  if (y < THRESHOLD_LOW)  dir += "DOWN ";
  if (x > THRESHOLD_HIGH) dir += "LEFT ";
  if (x < THRESHOLD_LOW)  dir += "RIGHT ";
  if (dir.length() > 0) {
    Serial.print("Joy: "); Serial.println(dir);
  }
  delay(100);
}

これを元に、実際のゲーム向けに改造してください

下記のポイントを実装すると、本番のクレーンゲームとして動くようになります。

  • HID キーボード化：#include <Keyboard.h> を追加し、Serial.println(...) を実際のキー送信に置き換える
    • 投下ボタン → Keyboard.press(' ')（Space）
    • スタートボタン → Keyboard.press(KEY_RETURN)（Enter）
    • ジョイスティック → Keyboard.press('w' / 'a' / 's' / 'd')
  • 押している間だけ入力：ジョイスティックは倒している間 press、戻したら release する
  • カウントダウン処理：スタート押下で 30 → 0 を 1秒ごとに減らす（delay ではなく millis() ベースが望ましい）
  • 3回繰り返し：1回（30秒）終わったら次のスタート待ち、3回終わったら待機状態に戻す
  • タイマー切れで強制投下：30秒経過時に自動で投下（Space 相当）を送る
  • LED 制御：ゲーム中は点灯、投下後に消灯（将来的には投下後3秒点滅 → 消灯）
  • チャタリング対策の見直し：delay() での簡易対策を、状態管理（前回値との比較）に置き換える
このあとの流れ

メンター側で簡単なデモサイトを用意します。コントローラーを PC に繋いで、そのデモサイトでクレーンが操作できる・投下できることを確認してもらう、というゴールです。
