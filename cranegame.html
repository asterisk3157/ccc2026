PROJECT 01 — CRANE GAME

デジタル
クレーンゲーム

自作レバーでクレーンを操作。景品が取れたら本物のお菓子をプレゼント。
子供が一番盛り上がる、王道のお祭りゲーム。

IN PROGRESS 6月頭 完成目標
取れたらお菓子！
01 — RULES

ゲームルール

PRICE

1プレイ ¥100

手動集金、係員がスタートボタンを押してゲーム開始。
DURATION

30秒 × 3回

1プレイで 30秒チャレンジを3回挑戦できる。タイマー切れで強制投下。
SCORING

取得個数で勝負

クリアしても残り時間内は続行可能。最大 3回 × 連続GET を狙える。
PRIZE

本物のお菓子

画面でクリア表示 → 係員がお菓子を手渡し。
02 — CONTROLLER

コントローラー仕様

HID キーボードのみ・Serial 通信なし
INPUT 01

スティック

  • 8方向操作（離すと停止）
  • HID キーボード入力：W / A / S / D
  • マイクロスイッチ × 4 想定
INPUT 02

投下ボタン（光る）

  • HID キーボード入力：Space
  • 押下で投下、内部で 7セグ = 00 表示
  • 内蔵 LED が点灯（プレイ中の合図）
INPUT 03

スタートボタン

  • HID キーボード入力：Enter
  • 係員が押してゲーム開始
  • 子供のフライング防止用
DISPLAY

7セグ × 2

  • 30秒カウントダウン
  • Arduino 内部で時間管理
  • 投下 or 時間切れで 00 表示
03 — TECH

使用技術

HARDWARE

Arduino Pro Micro

ATmega32U4 搭載で HID キーボード化が可能。Serial 通信を使わず、すべて HID 入力で完結。
SOFTWARE

Three.js または Unity

PC で動くゲーム本体。Three.js なら Web 配信可能、Unity なら高品質な 3D 表現可能。
RANKING

localStorage 保存

1プレイ（3回合計）の取得数で記録。名前なし、本日のトップ10をタイトル画面に常時表示。
CASE

卓上型 箱型筐体

ノートPCキーボード相当のサイズ。手前に筐体、奥にノートPC配置。USB 接続。
