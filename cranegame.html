Project 01 / Crane Game

デジタル
クレーンゲーム。

自作レバーでクレーンを動かす。
景品が取れたら、本物のお菓子をプレゼント。
6月頭完成 目標で動いている、第1作品。

IN PROGRESS 6月頭 完成目標
取れたらお菓子！
01

ゲームルール

RULES
Price 1プレイ ¥100
手動集金。係員がスタートボタンを押してゲーム開始。
Time 30秒チャレンジ × 3回
タイマー切れで強制投下。クリアしても、残り時間内は続けて狙える。
Score 取得個数で勝負
1プレイ（3回分）の合計取得数で、本日のランキング上位を狙う。
Prize 本物のお菓子
画面でクリア表示 → 係員がその場でお菓子を手渡し。
02

コントローラー

HID キーボード入力のみ
シリアル通信なし
Stick 8方向操作、離すと停止
HID 入力：W / A / S / D。マイクロスイッチ × 4 で構成。
Drop Button 光る大型ボタン
HID 入力：Space。押すと 7セグが 00、内蔵 LED は消灯する。
Start Button 係員用スタートボタン
HID 入力：Enter。子供のフライング防止のため、係員側で押す配置。
Display 7セグ × 2
30秒カウントダウン表示。Arduino 内部で時間管理するため、PC との通信は不要。
03

使用技術

TECH STACK
Hardware Arduino Pro Micro
ATmega32U4 搭載で HID キーボード化に対応。シリアル通信を使わず、すべて HID 入力で完結する設計。
Software Three.js または Unity
PC で動くゲーム本体。Three.js なら Web で配信可能、Unity なら 3D 表現の自由度が高い。
Ranking localStorage 保存
1プレイの取得数で記録。名前なし、本日のトップ10 をタイトル画面に表示。
Case 卓上型 箱型筐体
ノートPC キーボードくらいのサイズ。手前に筐体、奥にノート PC、USB で接続。
04

作業ステップ

STEPS
制作の流れ
  1. 01

    仕様確定

    ゲームルール、コントローラー構成、技術選定の方針を決める。
    完了
  2. 02

    筐体ラフ ＆ パーツデザイン

    手書きで以下をスケッチ：
    • 筐体の見た目イメージ
    • 投下ボタン・スタートボタン・スティックのデザイン
    • パーツの配置イメージ
    フレームワーク班 5/19まで
  3. 03

    Arduino 予習

    Wokwi（Web シミュレータ）で予習：
    • L チカ（LED 点滅）
    • ボタンを押すと LED が光る
    • シリアル通信で "Hello" を送信
    コントローラー班 5/19まで
  4. 04

    技術選定 ＆ 調査

    Unity と Web（Three.js）のどちらでクレーンゲーム本体を作るか決定。選んだ技術について調査する。
    ソフトウェア・アプリ制作班 5/19まで
  5. 05

    パーツ選定 ＆ 購入

    必要なパーツを選び、Amazon で購入してサークルに請求。Arduino Pro Micro × 2、スティック、ボタン、7セグ、LED など。
    メンター 5月中
  6. 06

    1号機モック制作

    Three.js でクレーンゲーム本体のモック ＋ Arduino コードを書いて、動く1号機を完成させる。これがチームの参考実装になる。
    メンター 5月中
  7. 07

    ゲーム本体の実装

    モックを土台に、本番用のゲーム本体を実装。UI・演出・ランキングまで含めて完成度を上げる。
    ソフトウェア・アプリ制作班 5月末〜6月頭
  8. 08

    筐体の 3D モデル化 ＆ 製作

    手書きラフをもとに、Blender で正確な 3D モデルを起こす。木材（ホームセンター）または 3D プリントで実物を作る。
    フレームワーク班 5月末〜6月頭
  9. 09

    2号機の組み立て

    1号機の回路を見ながら、2号機を半田付けで組み立てる。興味次第で参加（メンターがサポート）。
    コントローラー班 opt-in
  10. 10

    統合テスト ＆ リハ

    筐体に部品を組み込み、ゲーム本体と接続して通しで動かす。本番想定でテストと調整。
    全員 6月
  11. 11

    本番出展

    水辺で乾杯！利根運河で出展。1プレイ ¥100 で、子供たちと盛り上がる。
    全員 7月
